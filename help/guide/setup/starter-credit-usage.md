# Real-Time CDP Collaboration [!DNL Starter]中的信用使用量和消耗量

本文档提供了有关以受邀用户身份加入Adobe Real-Time CDP Collaboration [!DNL Starter]时如何使用积分的详细信息。 进一步了解谁负责信用使用情况，以及访问和管理的重要注意事项。

有关Collaboration [!DNL Starter]的一般概述，请阅读[Real-Time CDP Collaboration [!DNL Starter] 概述](../overview/starter-overview.md)。

## 信用使用的工作方式 {#credit-usage}

接受邀请后，邀请您的组织将涵盖您活动的所有信用使用。 积分始终从访客的帐户中扣除，并且不会从您自己的帐户中计费。

## 管理访问和期望 {#manage-access-and-expectations}

Collaboration **不**&#x200B;自动强制使用信用或可用性。 这意味着：

* 作为受邀用户，您必须直接与邀请您讨论信用使用的组织或合作伙伴进行协调。
* 您的邀请组织负责决定：
   * 何时可以访问和使用Collaboration功能
   * 关于信用消费的哪些限制、限制或治理

>[!IMPORTANT]
>
> Adobe不管理或仲裁组织之间的信用共享协议。 所有使用期望应直接在您和邀请合作伙伴之间商定。

有关如何在各组织之间分配积分的详细信息，请参阅[连接设置指南](../connect/establishing-connections.md)中的[积分拆分设置](../connect/establishing-connections.md#credit-split)部分。

要了解有关哪些活动使用信用以及如何跟踪或管理信用使用情况的更多信息，请参阅[跟踪您的信用使用活动](./my-activity.md)。
